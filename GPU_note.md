# GPU Threading Notes

This repository ships with `raytrace_threads.pdf`, which documents the GPU/CPU experiments:

- **Speedup vs. Thread Count:** plots wall-clock performance as workers increase so you can identify the saturation point.
- **Flame Graph:** captures where time is spent during a representative render.
- **Sample Images:** includes renders of the ring-of-spheres layout (close-pack diffuse ring with an overhead emissive ring) that correspond to the performance sections.

Refer to the PDF for the detailed charts and captured imagery.
